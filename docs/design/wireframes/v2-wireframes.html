Decisions to confirm before the build

  1. One-button first run (frame 1). Is that enough, or do you also want a short intro line about what Switchyard is?
  2. The glow (frame 2, note 3): build per-cell wait data so it's honest, or drop the glow and keep only the rings and hatching?
  3. The Root-cause table drops the Replays and Source columns (they move to Method). The spec said keep them; the test graders still parse the table either way.
  4. Legibility (design §Legibility): 1× = real time, smooth motion, destination lines on carrying robots, and focus mode. Approve.
  5. Console layout (frame 0): approve the left rail + inspector + timeline as the main layout.
  6. Dark theme only for V2, or add a light theme for screenshots and print?
